# HabitFlow – Your Personal Habit Tracker

A modern and intuitive habit-tracking web application designed to help users build consistency, stay motivated, and achieve their personal goals through daily habits.

 **Live Site URL: https://habit-tracker-a3358.web.app

---

## Features

- **Create & Manage Habits:** Add habits with titles, categories, reminders, and descriptions.
- **Track Daily Progress:** Mark habits as completed and maintain streaks automatically.
- **Streak Calculation:** Smart streak system that counts consecutive days from MongoDB data.
- **Public Habit Library:** Browse habits shared by other users and view habit details.
- **Search & Filter System:** Instantly filter habits by category and search by title or keywords.
- **User Dashboard:** View your own habits, completion history, and progress stats.
- **Responsive UI:** Fully responsive layout built with Tailwind CSS and modern animations.
- **Framer Motion Animations:** Smooth, modern transitions and effects throughout the app.
